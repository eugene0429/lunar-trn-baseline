# 결정 기록

원문(LVS 논문)에 수치가 없는 값, 데이터셋 규약을 직접 확인해 정한 값을 모두 여기에 남긴다. 코드의 기본값과 이 문서가 다르면 이 문서를 고친다. 항목마다 "값 / 근거 / 코드 위치"를 적는다.

| B3 | 투영 그림자는 접평면 직교좌표에서 태양 방위로 격자를 회전한 뒤 suffix-max 지평선 주사로 구한다(정확한 2.5D) | 광선추적과 97% 이상 일치(`tests/test_maps.py`). 계산량 O(N) |

| B5 | 정밀 지도 픽셀 = 명목 대역 고도의 카메라 GSD(1.0×), 거친 지도 픽셀 = 1.5×GSD. 지도는 대역마다 만든다(실제 고도가 아니라 명목 고도 3.5 + 3k km 기준) | LVS: 정밀 6 m ≈ 운용 고도 중간의 LCAM GSD, 거친 12 m ≈ 거친 단계 시작 고도 GSD의 1.46배. 처음에 쓴 "5·2^k m 반올림, 거친 = 2×정밀"은 9.5 km 대역에서 거친/GSD = 2.6이 되어 128 px 템플릿이 시야에 1–2개밖에 안 들어갔다(거친 성공 2%). 1.5배면 3×3 = 9개가 들어간다 |
| B6 | 지도 범위(반폭) = 시야 반폭 + 사전 반경 + (사전 반경 + 300 m) + 거친 템플릿 반폭 + 500 m | 사전 오차 안의 모든 시작점에서 거친 탐색 창이 지도 안에 들도록 |

## C. 거친 단계 (P3)

| ID | 값 | 근거 |
|---|---|---|
| C1 | 템플릿 128×128 (지도 px), 영상당 최대 9개, 템플릿 간격 ≥ 0.75 템플릿 | LVS는 영상 3장 × 5개. 단일 영상이라 수를 늘렸다 |

| C5 | 기하 이상치 검정 = 자세를 고정한 위치 RANSAC(2점), 재투영 임계 3 거친-지도 px | LVS의 \|a − m\| < T와 같은 역할. T 수치는 비공개. 3 px는 거친 피크의 부화소 오차보다 충분히 크다 |
| C6 | 거친 단계 통과 조건: 기하 inlier ≥ 2 | LVS "parameterized criteria"(비공개). 위치 3자유도에 2점이 최소 |
| C7 | 거친 피크 높이 ≥ 0.15(NCC), 폭(FWHM) ≤ 12 거친-지도 px | §E 보정. 정답 템플릿의 98.8%가 통과하고 오답은 45%가 통과한다. 남은 오답은 기하 RANSAC이 거른다 |

## E. 피크 임계값 보정

- **방법**
  - 보정 표본은 기하 순번 % 4 == 1인 113개다. 기하마다 조명 3종(지도 = 영상 조명)과 사전 2개로 678회 실행했다.
  - 피크 게이트를 끄고 실행한다(`scripts/run_v2.py --split calib --annotate --set fine.min_peak_height=-1 ...`).
  - 랜드마크마다 영상 좌표의 광선을 정답 자세로 지도 DEM에 교차시켜 참 지도 위치를 구한다. 정합 위치와의 차가 1.5 정밀-지도 px 미만이면 정답이다. 거친 템플릿은 2 거친-지도 px 미만이 정답이다.
  - 분석: `scripts/analyze_calib.py outputs/calib/nadir`
- **규칙**: 모든 대역에서 정답 정합의 98.5% 이상을 남기는 가장 엄격한 반올림 임계값을 고른다. 피크 게이트는 RANSAC 앞에서 이상치 부하를 줄이는 역할이다. 무결성은 기하·Mahalanobis 검정과 inlier 20 게이트가 맡는다. 그래서 정답 보존을 우선했다.
- **표본 규모**: 피크가 있는 정밀 랜드마크 99,000개(정답 92.2%), 거친 템플릿 4,196개(정답 81.5%)

| 신호 | 정답 분포 (5/50/95/99%ile) | 오답 분포 (5/50/95/99%ile) |
|---|---|---|
| 정밀 피크 높이 | 0.74 / 0.89 / 0.97 / 0.98 | 0.00 / 0.39 / 0.72 / 0.84 |
| 정밀 FWHM (px) | 3.6 / 4.9 / 8.0 / 10.3 | 3.9 / 7.6 / 20.8 / 36.5 |
| 정밀 부피크/주피크 | 0.43 / 0.58 / 0.81 / 0.89 | 0.65 / 0.93 / 0.99 / 1.00 |
| 정밀 PSR | 4.3 / 6.7 / 8.9 / 9.8 | 0.0 / 4.0 / 12.1 / 28.1 |
| 거친 피크 높이 | 0.24 / 0.66 / 0.90 / 0.93 | 0.07 / 0.14 / 0.51 / 0.72 |
| 거친 FWHM (px) | 4.3 / 5.8 / 8.6 / 11.1 | 4.4 / 7.0 / 12.7 / 17.2 |

| 정밀 게이트 (높이, 폭) | 정답 통과 | 오답 통과 | 정밀도 |
|---|---|---|---|
| ≥ 0.50, ≤ 12 | 0.994 | 0.175 | 0.985 |

- 처음 둔 임시값(정밀 높이 0.5, 폭 4 px)은 틀렸다. 정답 피크의 FWHM이 4–8 px라서 정답의 85%를 버렸다. 합성 장면 시험에서 먼저 드러났다.
- 부피크 비는 높이 다음으로 잘 가른다. LVS 게이트에는 없어서 게이트로 쓰지 않고 원신호로만 남긴다.
