# P-G 크레이터 패턴 매칭 기준선 — 설계

착수 핸드오프 §2.1의 두 번째 계열(P-G)을 만든다. 이번 범위는 **추적형(사전 자세 있음) 1단계**다. lost-in-space(LIS)는 이 결과로 검출기 품질을 확인한 뒤 별도 스펙(2단계)으로 한다.

## 1. 목적과 범위

### 1.1 목적

- T-I(LVS형)와 **같은 하네스·같은 사전 오차·같은 채점**으로 돌릴 수 있는 P-G 기준선을 만든다.
- 핸드오프 §6 **V7(추적형 절반)**을 하고, 계열 가설 **H-b**(조명 잔차가 클 때 P-G 무결성 > T-I)를 StereoLunar 조명 3종으로 처음 시험한다.
- 본 연구가 ROC를 만들 수 있게 원신호를 남긴다(§7).

### 1.2 범위

| 포함 | 제외 (이유) |
|---|---|
| DEM 기하 크레이터 카탈로그 추출(전 DEM, 1회 캐시) | LIS 식별기 → 2단계 스펙 |
| CNav식 그림자·밝은 영역 짝짓기 검출기 | 학습 검출기(Ellipse R-CNN 등) → 속성 실험으로 나중에 |
| 추적형 매칭: 위치 가설 투표 + 게이트 할당 + 기존 PnP 후단 | 핸드오프 F1 전면 리팩터(T-I를 공통 하네스로 이전) |
| `localize_craters()` 인터페이스, `run_pg.py` 실행기 | oblique 본 실행(시간이 남으면 표본만) |
| 보정(보정 표본) → 평가(V7) → T-I와 짝 비교(H-b) | 테두리 부화소 정제(Cheng식), 원뿔 기반 위치 해법 → 2단계 후보 |
| IM-2식 가시성 가지치기 **옵션**(기본 꺼짐)과 소규모 비교 | |

### 1.3 성공 기준

- V7 합격
  1. 평가 표본 전체에서 오고정 0건. 단측 95% Clopper–Pearson 상한을 함께 보고한다.
  2. 정답 고정의 수평 오차 95%ile ≤ 2 명목-GSD px (모든 대역).
  3. 다음 곡선을 보고한다: 고도별 매칭 크레이터 수, 크레이터 픽셀 지름별 검출 확률(재현율).
- H-b 보고: 영상 조명별 P-G 가용성·무결성을, 같은 사전 표본의 T-I V2(조명 일치)와 V3(교차, 태양 각도 차 66–134°)와 나란히 낸다.
- 가용성 자체는 합격 기준이 아니라 측정값이다(핸드오프와 같음).

## 2. 결정 요약

| 결정 | 근거 |
|---|---|
| 주 접근은 **CNav 충실형 고전 파이프라인 자체 구현** | 공개 정보가 충분한 비행·비행시험 P-G는 DLR CNav와 IM-2뿐이다. 둘 다 그림자–밝은 영역 짝짓기 검출기를 쓴다. CNav는 "Correct detection … is almost certain for all but the lowest camera elevation of 5° and illumination elevations above 55°"(Maass 2016)로, 낮은 태양(StereoLunar 15–20°)이 유리한 구간이다. 결정적이고 torch가 필요 없다 |
| wdoppenberg/crater-detection·ellipse-rcnn은 **코드·가중치를 쓰지 않는다** | 둘 다 MIT. 그러나 100–500 km 궤도용이고 위치 검증 함수가 30 km 미만을 기각한다. 크레이터를 고도 없는 구면 위에 둔다. 극점에서 특이점이 있다. `.pth`는 pickle, Hugging Face 가중치는 라이선스 표기가 없다. 학습 데이터는 SurRender가 필요하다. 원뿔 대수·Christian 불변량은 2단계 LIS에서 출처를 표기하고 다시 쓴다 |
| 카탈로그는 **같은 DEM에서 추출한 태양 무관 기하 카탈로그** | 핸드오프 결정. 태양과 무관해야 H-b를 깨끗하게 시험할 수 있다. IM-2식 가지치기(지도 태양으로 렌더해 검출된 것만 남김)는 옵션으로 둔다 |
| P-G의 "지도" = `CraterMap(catalog, sun_dir_world)` | 핸드오프 §8 시그니처(`trn_map`)를 지킨다. 태양 방향은 탑재 천체력으로 아는 값이다. T-I의 `TrnMap.sun_dir`에 해당한다 |
| 저고도 대사전 오차는 **위치 가설 투표**로 푼다 | ±3 km 사전 오차는 3.5 km 고도에서 영상 위 약 530 px(영상 폭 512 px 이상), 30.5 km에서 약 61 px다. 가까운 것끼리 짝짓기는 고고도에서만 된다 |
| 중심 편향을 보정한다 | 영상 타원의 중심은 3D 테두리 중심의 투영이 아니다. 3.5 km, 천저 이탈 30°에서 지름 1 km 크레이터는 약 4 px, 3 km는 약 38 px 어긋난다 |
| 사전 표본 시드를 `run_v2.py`와 같게 한다 | (기하, 영상 조명 j, 시행)마다 T-I V2 대각 실행(지도 조명 = j)과 같은 사전 오차가 나온다. 짝 비교가 된다 |
| 채점 허용치는 T-I와 같은 미터 값(3 × 명목 정밀 지도 px) | 계열 비교의 잣대를 같게 한다. "명목 정밀 지도 px"(명목 px)는 `experiments.fine_map_pixel(명목 대역 고도 / fx)`, 즉 T-I 정밀 지도 픽셀과 같은 값이다. P-G는 지도를 렌더하지 않지만 채점·보고 단위로 이 값을 쓴다 |
| 새 의존성 없음 | OpenCV(`connectedComponents`, `resize`), SciPy(`ndimage`, `linear_sum_assignment`), NumPy만 쓴다. 타원 적합은 직접 최소제곱(Fitzgibbon/Halir–Flusser)을 직접 구현한다 |

### 2.1 데이터에서 확인한 것 (설계 입력)

- 영상: 모든 고도대에 지름 4–15 px 작은 크레이터가 수십–수백 개 있다. 태양 고도 15–20°라 그림자와 밝은 벽이 짝을 이룬다. 큰 함몰 지형은 얕고 경계가 흐리다.
- DEM: `LDEM_875S_5M`의 고역 성분에 LOLA 궤적 보간 흔적(선을 따라 늘어선 지름 10–30 m 구덩이·돌기)이 강하다. 3.5 km 영상에도 점선으로 보인다. LOLA 극지 5 m DEM의 실측 채움률은 ~10%다(Barker). 작은 크레이터 카탈로그에 이 흔적이 섞이고, 규칙적 반복 패턴이라 매칭 모호성을 만들 수 있다.
- StereoLunar는 알베도가 일정하다. 영상에는 DEM 구조만 있으므로 DEM 카탈로그와 영상이 자기 일관적이다. T-I와 같은 종류의 통제된 낙관 조건이다.

## 3. 구조

```
src/lunar_trn/craters/
  __init__.py
  conics.py    # 3D rim ellipse <-> image conic, conic centre/axes, centre bias
  catalog.py   # CraterCatalog, extract_catalog(), build/load/query, prune option
  detect.py    # CNav-style shadow/lit region pairing detector
  match.py     # catalog projection, position-hypothesis voting, gated assignment
  localize.py  # CraterMap, CraterConfig, localize_craters()
scripts/
  build_catalog.py   # whole-DEM catalog, tiled, multiprocessing -> data/catalog/*.npz
  run_pg.py          # V7 / H-b runner (same prior seeds as run_v2.py)
  analyze_pg.py      # P-G tables; imports cp_upper/pct from analyze_v2.py, pairs with T-I runs.jsonl
```

- **T-I 코드는 바꾸지 않는다.** 다만 `LocalizationResult`에 `family: str = "T-I"` 필드를 추가한다(기본값이 있으므로 기존 호출은 그대로).
- **재사용**: `pose.ransac_position`(자세 고정 2점), `pose.refine_pose`(6자유도 GN, 자세 MAP 사전, Huber), `pose.mahalanobis_gate`(LVS 규칙), `health.scene_signals`, `experiments.sample_prior/score/fine_map_pixel`, `frames`, `camera.PinholeCamera`(u = col + 0.5), `render.stereo_tangents`(극점에서도 정의되는 국지 기저), `dem.DemSource`.

### 3.1 데이터 흐름

```
DEM ──build_catalog (1회)──> CraterCatalog (태양 무관, 전 DEM)
                                   │ query(prior footprint + 3σ + 여유)
image, K, prior T, prior cov, sun ─┤
        │                          ▼
        ├─ detect ─> 검출 타원들     예측 타원들(사전 자세 투영, 크기·가시성 선택)
        │                 └──────┬──────┘
        │                  위치 가설 투표 (상위 K개)
        │                        ▼
        │        가설마다: 게이트 헝가리안 → 위치 RANSAC → 편향 보정 + 6자유도 GN
        │                 → Mahalanobis 게이트 → 재할당·재정제
        │                        ▼
        └──────────> 최다 inlier 가설 → 고정 게이트 → LocalizationResult(family="P-G")
```

### 3.2 인터페이스

```python
from lunar_trn.craters.catalog import CraterCatalog
from lunar_trn.craters.localize import CraterMap, CraterConfig, localize_craters

catalog = CraterCatalog.load("data/catalog/ldem_875s_5m_craters.npz")
cmap = CraterMap(catalog=catalog, sun_dir_world=sun)   # Sun from the onboard ephemeris
result = localize_craters(image, K, prior_T_world_cam, prior_cov, cmap, CraterConfig(), seed=0)
# result.family == "P-G"; status / T_world_cam / cov / landmarks / health / stage as for T-I
```

`stage`는 `"detect"`, `"match"`, `"pose"` 중 마지막으로 도달한 단계다.

## 4. 카탈로그 추출

전 DEM을 한 번 처리해 `data/catalog/`에 캐시한다(커밋 안 함). 타일은 8 km에 겹침 ≥ 2 × 최대 지름이고, 64코어로 병렬 처리한다.

### 4.1 크레이터 표현

크레이터마다 다음을 저장한다.
- 테두리 평면의 3D 중심 `X_c`(MOON_ME, m)와 평면 법선 `n`
- 평면 안 기저 `(e1, e2)`: 극 평사 격자 접선(`render.stereo_tangents`)을 법선에 직교화한 것. 극점에서도 정의된다
- 반축 `a ≥ b`(m), 장축 각 `ψ`(e1 기준)
- 원신호(필터에도 씀): 깊이 `d`(평균 테두리 높이 − 바닥 최저), `d/D`(D = 2√(ab)), 테두리 완결도(유효 방위 비율), 테두리 높이 표준편차, 타원 적합 RMS, 씨앗 LoG 응답, 추출 층(DEM 피라미드 단계)
- 평사 좌표 `(x, y)`: 영역 조회용 격자 색인

### 4.2 절차

1. **피라미드**: DEM을 블록 평균해 5–320 m의 7개 층(×1–64)을 만든다. 씨앗 반지름은 층당 5/6.3/7.9 층-px이고 테두리 탐색이 0.5–1.6배를 덮는다. 지름 범위는 50 m–6 km다(상한 6 km = 최고 대역 49 m/px에서 128 px).
2. **씨앗**: 층마다 DEM의 척도 정규화 LoG(σ = 0.45·r, 층당 3척도)를 구하고, (x, y, 척도) 국소 최대를 찾는다. 응답을 깊이 대리값으로 바꿔 `d/D` 대리값 ≥ 0.02인 것만 남긴다. σ = 0.45 r은 테두리 있는 사발형의 LoG 최대 척도다. 처음 둔 σ = r/√2(가우스 함몰 가정)는 반지름을 0.6배로 과소평가해 큰 크레이터를 놓쳤다(계획 단계 합성 시험).
3. **테두리 단면**: 씨앗마다 48방위 방사 단면을 쌍선형 보간으로 0–1.8r까지 뽑는다. 1.5r–2.5r 고리에 평면을 맞춰 국지 기울기를 뺀다. 방위마다 [0.5r, 1.6r] 안의 최대 높이를 테두리점으로 둔다. 테두리가 안쪽 바닥보다 0.2 m 넘게 높고(평평한 면 배제), 구간 끝이 아니며, 바깥 끝보다 높으면 유효로 친다.
4. **적합**: 유효 테두리점(국지 접평면 좌표)에 `cv2.fitEllipseDirect`를 맞춘다. 잔차 > 2.5·MAD인 점을 빼고 두 번 다시 맞춘다. 테두리점 (x, y, h)에 평면을 맞춰 법선을 구하고, 중심을 평면에 올린다.
5. **바닥과 깊이**: 0.5배 타원 안의 매끈한 DEM 최저값을 바닥으로 둔다. 깊이와 d/D를 계산한다.
6. **필터(기본값, G3)**: 50 m ≤ D ≤ 6 km, 완결도 ≥ 0.7, a/b ≤ 1.5, d/D ≥ 0.04.
   - LOLA 흔적(지름 10–30 m)은 D ≥ 50 m로 대부분 빠지지만, 계획 단계 점검에서 50–65 m 항목이 궤적선을 따라 남는 것을 확인했다. 그래서 카탈로그 하한 80 m 조건을 민감도 실험으로 함께 돌린다(§9.4).
   - 계획 단계 점검(실 DEM·실영상 오버레이)에서 영상에 선명한 크레이터 다수가 카탈로그에 없었다. 보정 단계에서 "검출됐지만 카탈로그에 없는" 크레이터마다 탈락 사유를 진단하고(`explain_rim`), 정해진 규칙으로 필터를 한 번 완화한다(§8).
7. **중복 제거**: 층·타일 사이에서 중심 거리 < 0.3·작은 쪽 D이고 크기 비 < 1.5면, (완결도 × LoG 응답)이 큰 것을 남긴다.

### 4.3 확인

- 합성 DEM 시험(§10)
- 실 DEM 오버레이 그림: 고도대별 대표 장면 4개에 카탈로그 타원을 정답 자세로 영상에 투영해 겹쳐 본다. `docs/validation/` 그림으로 남긴다.
- 크기 분포: 누적 크기분포가 r⁻² 근처인지(Minton 2019 평형) 확인한다. D < 100 m 부분이 비정상적으로 꺾이면 DEM 실효 해상도의 영향으로 기록한다.

### 4.4 가지치기 옵션 (기본 꺼짐, IM-2식)

- `prune_catalog(catalog, src, sun_dir, center_xy, half_size_m, pixel)`: 주어진 태양으로 정사 지도를 렌더(`maps.render_map`)하고 최소–최대 정규화한다. 같은 검출기를 지도에 돌리고, 지도 좌표에서 카탈로그와 짝지어 보이는 크레이터 표지(bool 배열)를 낸다.
- 실행기는 그 부분 카탈로그를 `CraterMap`에 넘긴다(설정 플래그 대신).
- 비교 실험(§9.3) 외에는 쓰지 않는다.

## 5. 검출기 (CNav식)

입력은 영상(float), 카메라, 사전 자세, 태양 방향이다. 출력은 검출 타원(중심 u, v; 반축 a, b px; 각; 영역 원신호)이다.

1. **고역 정규화**: I_hp = (I − G_σL∗I) / 국소 표준편차, σL = 25 px. 큰 음영 기복을 지운다. 지름 > ~60 px 크레이터를 위해 1/2, 1/4 축소 영상에서도 같은 과정을 돌린다(층 3개).
2. **영역**: CNav 방식 그대로 I_hp에 문턱 스윕(0.5–2.5σ, 7단계)을 걸어 어두운·밝은 연결 성분을 얻는다. 연속한 문턱 사이에서 무게중심 이동이 작고(≤ max(1 px, 0.25 r_eq)) 면적이 절반 이상 남으면 "안정"으로 보고, 중첩 사슬마다 가장 느슨한 안정 영역을 쓴다. CNav 원문은 "largely similar to the MSER image feature detector, but with alternative and simpler stability criteria"다. 처음 안의 OpenCV MSER 대신 이 방식을 택한 이유는 원문에 더 충실하고 OpenCV 버전별 MSER API 차이를 피하기 위해서다(계획 단계 변경).
3. **영상 안 태양 방향**: 검출 위치마다, 사전 거리의 지면점 X에서 태양 쪽으로 조금 옮긴 점의 투영 차로 구한다. 원근에서 방향이 화면 위치에 따라 바뀌는 것까지 반영한다.
   - 기본 출처는 **천체력(입력 태양 + 사전 자세)**이다.
   - CNav의 영상 추정(어두운→밝은 변 방향 히스토그램에서 π 폭 창의 각분산 최소)도 계산해 원신호로 남긴다. 설정 `sun_source="image"`로 바꿀 수 있다.
4. **짝짓기(CNav 규칙)**:
   - 어두운 영역마다 가장 가까운 밝은 영역 2개를 후보로 둔다.
   - 면적비 > 10인 짝은 뺀다(CNav 원문 값).
   - 어두운→밝은 방향이 반태양 방향에서 θ_pair 이상 벗어나면 뺀다. 그림자는 크레이터 안 태양 쪽 벽에, 밝은 벽은 반대쪽에 생긴다.
   - 중심 거리가 짝 크기 대비 너무 먼 것을 뺀다(≤ 1.5·√(면적합/π)).
   - 영역 하나는 짝 하나에만 쓰고, 방향 편차가 작은 순으로 탐욕 배정한다.
5. **타원**: 두 영역 화소 합집합의 2차 모멘트(주성분) 타원을 쓴다(CNav: "principal components ellipses over the union of their constituent image support points").
   - 반축 = κ·2√λ.
   - 중심 = 합집합 무게중심 + β·a·(반태양 방향 단위벡터). 낮은 태양에서는 그림자 쪽 면적이 커서 무게중심이 태양 쪽으로 치우친다. 이 편향은 모든 크레이터에 공통이라 위치 공통모드 오차가 되므로 보정한다.
   - κ, β는 보정 표본에서 정한다(§8).
6. **크기 범위**: D_px = 2√(ab)가 [D_min_px, D_max_px]인 것만 남긴다. 기본은 [6, 128]이고, 하한은 보정의 재현율 곡선으로 정한다.

## 6. 매칭·자세·게이트

### 6.1 후보 선택

- 사전 위치 둘레 (시야 반폭 + 3σ_h + 300 m) 안의 카탈로그를 조회한다.
- 사전 자세로 각 크레이터의 테두리 원뿔을 투영해(`conics`), **원뿔 중심**과 크기를 예측한다.
- 예측 D_px가 [0.7·D_min_px, 1.3·D_max_px]이고 카메라 앞에 있는 것만 남긴다.
- 선택: 런타임 가시성 필터. 국지 태양 고도 e에서 d/D ≥ c_vis·tan(e)/4(벽 기울기 ≈ 4·d/D가 e보다 커야 안쪽 그림자가 생긴다)인 것만 쓴다. 기본 켤지와 c_vis는 보정 표본 재현율로 정한다(G8). 카탈로그는 바꾸지 않으므로 태양 무관 성질은 유지된다.

### 6.2 위치 가설 투표

- 자세를 알고 수직 사전이 좁으므로(±120 m), 짝 (검출 i, 카탈로그 j) 하나가 카메라 위치 가설 하나를 준다. 검출 광선 d_i(세계)를 따라 c = X_j − t·d_i로 두고, c가 사전 위치와 같은 높이(사전 위치의 국지 연직 성분)가 되도록 t를 정한다.
- 크기 호환인 짝만 투표한다: |ln(D_px,i / D_px,j)| < ln 1.6.
- 사전 위치의 ENU 수평면에서 반경 3σ_h + 300 m(T-I 거친 탐색과 같은 값, C3)의 격자에 표를 쌓는다.
  - 격자 칸 = 2 × 영상 GSD(사전 거리 기준).
  - 칸 1개 폭으로 가우스 평활한다.
  - 상위 K = 3 봉우리를 뽑는다. 봉우리 사이 배제 반경은 max(4칸, 시야 폭의 10%)다.
- 원신호: 1·2위 표 수와 비, 투표한 짝 수.

### 6.3 가설 검증 (가설마다)

1. **1차 할당**: 가설 위치로 카탈로그를 다시 투영한다. 게이트는 중심 거리 ≤ max(4 px, 0.4·D_px)이고 크기 비 ≤ 1.6이다. 비용(정규화 중심 거리 + |ln 크기비|)으로 `linear_sum_assignment`를 돌린다.
2. **위치 RANSAC**: `ransac_position`(자세 고정 2점)을 임계 t_r(기본 3 px)로 돌린다.
3. **편향 보정 + 정제**:
   - 측정을 uv_i − δ_j로 바꾼다. 여기서 δ_j = (현재 자세로 투영한 원뿔 중심) − (X_j의 투영)이다.
   - `refine_pose`(6자유도, 자세 MAP 사전, Huber)를 크레이터별 σ_px,i = max(σ_min, s·D_px,i)로 돌린다.
   - δ를 갱신하며 2회 반복한다.
4. **Mahalanobis 게이트**: LVS 규칙 γ = q3 + 1.5·(q3 − q1)을 쓴다(D8과 같음).
5. **2차 할당**: 정제된 자세에서 좁은 게이트(max(2 px, 0.2·D_px))로 다시 할당한다. 그 뒤 3–4단계를 한 번 더 한다. LVS 정밀 반복 2회(D9)에 해당한다.

가설 중 최종 inlier가 가장 많은 것을 고른다. **가설별 inlier 수를 모두 기록한다.** 1·2위 가설의 inlier 차는 모호성 원신호다.

### 6.4 고정 게이트와 공분산

- **고정**: inlier ≥ 5 ∧ 카탈로그 매칭 비율(inlier / 시야 안 카탈로그) ≥ r_min ∧ σ0 ≤ s_max (G12).
  - inlier 5는 CNav 남극(영상 크레이터 최소 5개가 카탈로그에 있을 때 고정)이다. 매칭 비율은 SLIM이 비행에서 쓴 영역별 크레이터 매칭 비율 임계와 같은 역할이고, σ0는 LVS Mahalanobis와 같은 일관성 검사다.
  - 계획 단계 사전 점검(보정 표본 29기하, 보정 전 검출기)에서 저고도 오고정 12건은 inlier 10–15개였다. 고고도 정답의 inlier 중앙값(13–18)과 겹쳐 inlier 수만으로는 가를 수 없었다. 반면 오고정은 σ0 1.93–2.36, 매칭 비율 0.03–0.08이었고, 정답은 σ0 95%ile 1.51, 매칭 비율 5%ile 0.10이었다.
  - 규칙: s_max = 정답 σ0의 99.5%ile(0.05 단위 올림). r_min = σ0 게이트를 통과한 오답이 남지 않는 가장 작은 매칭 비율(0.01 단위). 평가에서는 inlier 5와 20의 재판정 가용성도 함께 보고한다.
- **공분산**: `refine_pose` 공분산(σ0 > 1이면 σ0²로 키움)에 P-G 전용 공통모드 바닥을 더한다. 바닥은 T-I D7b와 같은 절차로 보정 표본의 정답 고정에서 정한다(G13). 바닥 이전 값은 `health["cov_landmark_only"]`에 둔다.

## 8. 보정 (보정 표본만)

- **표본**: T-I와 같은 보정 표본(기하 순번 % 4 == 1, 113개) × 영상 조명 3 × 사전 2 = 678회. `--annotate`로 실행한다.
- **정답 주석**: 정답 자세로 카탈로그 원뿔을 투영한다.
  - 검출은 최근접 예측 중심이 max(2 px, 0.25·D_px) 안이고 크기 비 ≤ 1.5면 "카탈로그 대응 있음"이다. 그 밖은 "대응 없음"(카탈로그에 없는 실제 크레이터이거나 오검출)이다.
  - 카탈로그 쪽은 시야 안 D_px ≥ 4인 것마다 같은 허용치로 검출 여부를 단다 → 재현율.
- **정하는 값과 규칙** (모두 G 항목으로 decisions.md에 남긴다):

| 값 | 규칙 |
|---|---|
| κ(크기 척도) | 대응 있는 검출의 D_px,카탈로그 / D_px,검출 중앙값 |
| β(태양 축 중심 편향) | 대응 있는 검출의 (예측 중심 − 검출 중심)의 반태양 축 성분 / a 의 중앙값 |
| θ_pair | 대응 있는 짝의 방향 편차 98.5%ile (T-I §E의 정답 보존 규칙과 같음) |
| D_min_px | 재현율 ≥ 0.5가 되는 가장 작은 D_px (반올림) |
| σ_px 모형 (σ_min, s) | 대응 있는 검출의 보정 후 잔차를 D_px 구간별 강건 표준편차로 맞춘다 |
| 가시성 필터 (켬/끔, c_vis) | q = d/D ÷ (tan e/4). 재현율(q < 0.75) < 0.2이고 재현율(q ≥ 1) ≥ 2배면 켠다. c_vis는 재현율 0.2 경계 |
| 카탈로그 필터 완화(한 번) | "검출됐지만 카탈로그에 없는" 크레이터의 탈락 사유 중 필터(완결도·편평도·d/D) 하나가 30% 이상이면, 그 크레이터들의 80%가 통과하는 값으로 완화하고 카탈로그를 다시 만든다. 씨앗·중복 제거 누락이 30% 이상이면 씨앗 임계를 절반으로 |
| 고정 게이트 (s_max, r_min) | §6.4 규칙. 카탈로그 하한 50 m, 80 m 조건마다 따로 |
| 공통모드 바닥 | 정답 고정의 축별 RMS(명목 px). T-I D7b 절차 |

- 평가 표본으로 임계값을 바꾸지 않는다(T-I와 같은 규약).
- 부산물: **크레이터 픽셀 지름 × d/D × 태양 고도별 검출 확률 곡선**. 주 보고서 열린 질문 8("하강 영상에서 픽셀 지름별 검출 확률 곡선")에 대한 첫 자료다.

## 9. 검증

### 9.1 V7 — 추적형 (조명 일치에 해당)

- **표본**: 평가 표본 337 기하 × 영상 조명 3 × 사전 6 = 6,066회. T-I V2 평가와 같은 표본·같은 시드(지도 조명 = 영상 조명으로 둔 시드식)다.
- **채점**: 고정(inlier ≥ N_min)이면서 수평 오차 ≤ 3 × 명목 정밀 지도 px(미터, T-I와 같은 값)면 정답, 넘으면 오고정. 고정 아니면 고정 없음이다.
- **보고** (대역별):
  - 가용성
  - 오고정 수와 상한95
  - 정답 오차 50/95/99%ile(m, 명목 px)
  - 수직 오차
  - 매칭 크레이터 수 분포
  - 투표 비·가설 inlier 차 분포(정답 대 고정 없음)
  - 실행 시간
- **짝 비교**: 같은 (기하, 조명, 시행)의 T-I V2 결과와 나란히 낸다. 가용성 차를 장면 신호(그림자 비율, 엔트로피)별로도 본다. 이것으로 H-a 경향을 처음 본다.

### 9.2 H-b — 조명 잔차

- P-G에는 지도 조명이 없다. 그래서 영상 조명 j의 P-G 결과 하나를 T-I의 (지도 k, 영상 j) 모든 쌍과 비교한다. 대각은 V2, 비대각은 V3(태양 각도 차 66–134°에서 T-I 가용성 0–2%)이다.
- T-I 방위 스윕 곡선(태양 각도 차별 가용성) 위에 P-G 가용성을 수평선으로 겹쳐 그린다.

### 9.3 가지치기 옵션 비교 (소규모)

- 평가 표본의 4번째 기하마다(약 84개) × 영상 조명 3 × 사전 2.
- 지도 태양 k로 가지친 카탈로그(k = j, k ≠ j)로 돌린다.
- 기하 카탈로그 대비 가용성·무결성을 보고한다. 가지치기가 P-G에 지도 태양 의존을 다시 들여오는지 보는 것이다.

### 9.4 카탈로그 하한 민감도 (H-c)

- 평가 표본 전체를 카탈로그 하한 80 m(`match.catalog_D_min_m=80`, 자체 게이트 보정)로 한 번 더 돌린다.
- 50 m 대 80 m의 대역별 가용성·오고정을 낸다. 저고도 하한이 카탈로그 최소 크기에 얼마나 묶이는지(H-c), LOLA 흔적의 영향이 어느 정도인지를 본다.

## 12. 위험과 대응

| 위험 | 대응 |
|---|---|
| 모멘트 타원이 테두리가 아니라 그림자·밝은 벽 모양을 따라가 중심·크기 편향 | κ, β 보정. 남는 편향은 공통모드 바닥으로 공분산에 반영. 2단계 후보로 Cheng식 테두리 정제 |

| 영상에 보이는 크레이터가 카탈로그에서 빠짐(완결도 필터 등) | 보정 단계 누락 진단과 한 번의 규칙적 완화 |

| 큰 크레이터가 완전히 그림자에 잠겨 밝은 영역이 없다 | CNav와 같은 알려진 한계. 재현율 곡선에 드러나게 둔다 |
| 카탈로그·영상이 같은 DEM이고 알베도 일정 → 낙관 편향 | 이 레포 목적(구현 검증)에 맞는 통제 조건. 보고서에 명시. "진실 ≠ 지도"는 본 연구에서 |
| 전 DEM 카탈로그 추출 시간·메모리 | 타일 병렬, 층별 처리. 먼저 StereoLunar 시야가 닿는 타일만 만들 수 있게 한다 |

## 15. 계획 단계에서 바뀐 점 (2026-10-12)

구현 계획을 쓰며 계획 코드를 스크래치패드에서 합성 시험과 실데이터 소규모 실행으로 미리 검증했다. 그 결과로 바꾼 것:

1. 검출 영역: OpenCV MSER → CNav 임계 스윕(§5).
2. 카탈로그 씨앗 척도 σ = 0.45 r, 피라미드 ×64·D 상한 6 km, 테두리 최소 기복 0.2 m(§4.2).
3. 고정 게이트: inlier 수 단독 → inlier ≥ 5 ∧ 매칭 비율 ∧ σ0(§6.4).
4. 카탈로그 하한 80 m 민감도 조건 추가(§9.4).
5. 카탈로그 누락 진단과 한 번의 규칙적 완화(§4.2, §8).
6. 가지치기는 표지 대신 부분 카탈로그로 전달(§4.4).

사전 점검 수치(계획 검증용, 보정 표본 일부, 보정 전 설정)는 결과가 아니다. 9.5–30.5 km에서 거의 전부 정답(중앙 오차 0.6–0.9 명목 px), 3.5–6.5 km에서 정답 약 78%와 오고정 12건이었고, 오고정은 모두 σ0 게이트로 걸러졌다.
